# Coffee Shop Application

Console-based Coffee Shop ordering system in C# (.NET 8), built for the
Software Construction Lab (Bahria University Karachi).

- **Lab 8:** Refactored Coffee Shop code (menu, orders, payment processing)
- **Lab 9:** MSTest unit tests for order amount calculation and payments
- **Lab 10:** Version control with Git & GitHub

## Run
```
dotnet run --project CoffeeShopApp
```

## Test
```
dotnet test
```
